# 🎓 مُساعد الجامعة

## ✨ المميزات

### 📚 الدراسة
- **الجدول الأسبوعي** التفاعلي مع كشف التعارضات تلقائياً
- **تقويم أكاديمي ديناميكي** (بداية الفصل، الإجازات، الاختبارات النهائية)
- **المقررات** مع لون مخصص لكل مادة وصفحة تفاصيل شاملة
- **المهام والاختبارات** مع أولويات، أنواع، وتنبيهات ذكية

### 📊 الأداء الأكاديمي
- **حساب المعدل التقديري** (من 5) من المقررات المسجّلة + الخارجية
- **درجات تفصيلية** لكل مقرر (واجبات، كويزات، ميدتيرم، نهائي)
- **تتبع الحضور والغياب** مع حد الحرمان (25%)
- **أرشيف الفصول** لحفظ واستعادة أي فصل سابق

### 🚀 الإنتاجية
- **مؤقّت بومودورو** يعمل في الخلفية مع إشعارات تلقرام
- **متابعة النوم والماء** مع رسوم بيانية أسبوعية
- **تذكير تفريش الأسنان** مرتين يومياً

### 💰 المصروف
- **إدارة الراتب** بدورة تلقائية شهرية
- **تصنيف المصاريف** في 11 فئة بأيقونات
- **أهداف مالية** مع حصالة وتتبع إيداعات

### 🤖 ذكاء اصطناعي
- **إضافة سريعة بالـ AI**: اكتب "تغديت مع الشباب بـ 45 ريال" → يسجل المصروف
- **قراءة الصور**: ارفع صورة التقويم الأكاديمي → يفهمها ويسجلها

### 📱 التكامل
- **يعمل أوفلاين** بالكامل (Service Worker + Cache)
- **مزامنة سحابية** عبر تلقرام (Worker API)
- **إشعارات فورية** للبومودورو والمهام
- **قفل شاشة آمن** برمز سري
